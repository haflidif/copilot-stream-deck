# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, assume good intent and keep discussions about the work. Harassment, personal attacks, discriminatory language and sharing other people's private information are not accepted in issues, pull requests or any other project space.

## Reporting

If someone's behaviour makes you uncomfortable, use GitHub's **Report content** option on the comment, issue or pull request (the `...` menu) and choose to report it to the repository maintainers. Reports are handled privately by the maintainer, [@haflidif](https://github.com/haflidif).

You can also [report abuse directly to GitHub](https://docs.github.com/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

## Enforcement

The maintainer may edit or remove comments, close issues or pull requests, and block people from the project when the Code of Conduct is not followed. The [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) in the Contributor Covenant are used as the reference.
