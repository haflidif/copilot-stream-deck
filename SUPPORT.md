# Support

This is an unofficial community project. It isn't supported by GitHub or Elgato, so please don't contact their support about it.

## Getting help

1. Check the [documentation](docs/index.md), in particular [How it works](docs/how-it-works.md), which explains common states such as **No bridge** and **Bridge not running**.
2. Search the [existing issues](https://github.com/haflidif/copilot-stream-deck/issues?q=is%3Aissue), including closed ones.
3. If you can't find an answer, open a new issue with the [bug report](https://github.com/haflidif/copilot-stream-deck/issues/new?template=bug_report.yml) or [feature request](https://github.com/haflidif/copilot-stream-deck/issues/new?template=feature_request.yml) form.

Help is given on a best-effort basis by the maintainer and the community.

## Security

To report a vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening an issue.
