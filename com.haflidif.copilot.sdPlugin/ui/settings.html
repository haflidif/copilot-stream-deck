Before using it

  
Build this repository, then load the Stream Deck extension in the Copilot app. Keep that session open. The bridge uses an authenticated local connection; no GitHub token is entered here.

  
Projects and session status come from the app. Model, context, credits and MCP controls apply only to the attached bridge session. Favorites are saved by this plugin, not synced with app pins. Voice is not connected yet.
